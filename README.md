Лаконічний та сучасний сайт-візитка з темною темою, розроблений для презентації навичок, досвіду та швидкого зв'язку.

---

## 🛠 Огляд та особливості

- **Сучасний візуальний стиль:** Використання ефекту матового скла (Glassmorphism), градієнтів та плавної анімації при наведенні.
- **Адаптивна верстка:** Повна підтримка мобільних пристроїв і десктопних моніторів завдяки Flexbox та Media Queries.
- **Чиста структура коду:** Семантичний HTML5 і структурований CSS без важких сторонніх бібліотек.

---

## 💻 Стек технологій

- **HTML5** — Семантична розмітка сторінки 
- **CSS3** — Стилізація
